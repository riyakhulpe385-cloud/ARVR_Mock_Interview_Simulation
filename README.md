# AR/VR Mock Interview Simulation System

An academic project focused on designing an immersive AR/VR-based interview simulation system to enhance placement readiness and communication skills.

---

## 📌 Project Type

Academic Research + System Design Project

---

## 📌 Overview

This project presents the design and partial implementation of an AR/VR-based mock interview simulation system. The system aims to simulate real interview environments, helping users improve communication skills, confidence, and overall interview performance.

---

## 🎯 Objective

To develop an immersive and scalable interview preparation system using AR/VR concepts, enabling realistic and repeatable mock interview experiences for students.

---

## 🚀 Features

* Simulated interview environment
* Role-based interaction (Student & HR)
* Structured interview question flow
* Basic interaction using Unity
* Scalable and repeatable practice system

---

## 🛠 Technologies Used

* Unity (Game Engine)
* C#
* AR/VR Concepts
* System Design & Analysis
